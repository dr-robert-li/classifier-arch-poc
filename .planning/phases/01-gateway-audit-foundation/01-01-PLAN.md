<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chat client → gateway | Untrusted request body (conversation_id, messages) crosses into the gateway; validated by Pydantic |
| gateway → Ollama (:11434) | Gateway is the sole crosser; clients must never reach Ollama directly (GATE-03) |
| Ollama response → gateway control flow | Model output is untrusted data; it must never alter gateway routing/policy decisions |
| gateway → local disk (SQLite + JSONL) | Audit artifacts hold raw prompts/responses; files restricted to owner (0o600) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | Gateway network binding | mitigate | Bind to 127.0.0.1 only via `settings.gateway_host`; never 0.0.0.0 (RESEARCH Pitfall 4). Verified by run command + acceptance criteria. |
| T-01-02 | Information Disclosure | SQLite db + JSONL audit files (contain raw prompts/responses) | mitigate | `os.chmod(..., 0o600)` on db file (get_connection) and on first JSONL write (_append_jsonl) — owner read/write only. |
| T-01-03 | Tampering | Audit log integrity | mitigate | JSONL is append-only with `fcntl.flock` LOCK_EX + fsync; SQLite events keyed on UUID5 primary key — no in-place rewrite path in Phase 1. |
| T-01-04 | Elevation of Privilege | Prompt injection via assistant model output | mitigate | Control flow (capture order, route decisions) lives entirely in deterministic gateway code; model output is treated as opaque content only and never parsed for instructions. Boundary established this phase. |
| T-01-05 | Spoofing / Tampering | Direct client → Ollama bypass | mitigate | GATE-03 module boundary: only `ollama_assistant.py` references :11434; enforced by the `test_architecture` grep test in CI. |
| T-01-SC | Tampering | pip installs (fastapi, uvicorn, pydantic, pydantic-settings, httpx, pytest, starlette) | accept | All 7 packages rated [OK] by slopcheck on PyPI per RESEARCH Package Legitimacy Audit (6–15+ yr old, very-high-download, canonical repos). No [ASSUMED]/[SUS]/[SLOP] — no blocking checkpoint required. |
