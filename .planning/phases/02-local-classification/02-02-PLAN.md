## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Denial of Service | orchestrator guard call | mitigate | Guard call inherits the shared httpx timeout; GuardUnavailableError on timeout → scanner-only fallback, no hang |
| T-02-07 | Elevation/Bypass | REL-02 fail-open risk | mitigate | classify_text catches GuardUnavailableError but PRESERVES scanner findings so a scanner-detectable secret still raises overall_severity to high even with guard down |
| T-02-08 | Information Disclosure | /classify response body | mitigate | Response carries categories/severity/hashed findings only; deterministic_findings store sha256 matched_value (from 02-01), never raw secrets |
| T-02-09 | Tampering | guard prompt-injection via /classify | accept | Guard call is isolated; orchestrator never lets guard output downgrade a scanner-high finding (max_severity is monotone) |
| T-02-SC | Tampering | npm/pip installs | accept | No new packages (stdlib + existing httpx/fastapi/pydantic only) |
</threat_model>
